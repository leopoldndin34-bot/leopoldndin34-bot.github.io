# Portfolio — Léopold César N’DIN

Site personnel d’ingénieur Travaux Publics (Méthodes & BIM), publié avec GitHub Pages.

- `index.html` : page d’accueil (profil, parcours, compétences, projets, CV, contact)
- `projets/` : une page par étude de cas
- `assets/css/style.css` : couleurs et mise en page (variables en haut du fichier)
- `assets/js/main.js` : menu, filtres, visionneuse d’images, formulaire
- `assets/img/` : images (une sous-dossier par projet)
- `assets/docs/CV_Leopold_Cesar_NDIN.pdf` : le CV téléchargeable — remplacez ce fichier en gardant le même nom pour mettre le CV à jour
- `_source/` : générateur facultatif (ignoré par GitHub Pages)
